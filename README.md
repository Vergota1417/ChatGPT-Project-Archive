# ChatGPT Project Archive

Persistent archive of small code projects and downloadable revisions.

## YouTube Smart Skip Watcher

The original Tampermonkey userscript and experimental revisions are stored in `YouTube-Smart-Skip/`.

- **v2.0.0** – originally supplied userscript (preserved for comparison)
- **v2.0.2** – performance-limited experimental patch, **not confirmed to skip ads on the current YouTube player**
- **v2.1.0** – alternate experimental implementation

Use **Tampermonkey → Dashboard → Import from File** to install a `.user.js` file. Disable other versions first.

The downloaded archives preserve old versions for troubleshooting. YouTube may reject programmatic click events; no revision here has been verified to overcome that restriction.
